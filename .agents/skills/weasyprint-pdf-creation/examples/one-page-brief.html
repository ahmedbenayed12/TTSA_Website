Should we replace markdown PDFs?

Markdown exports are fast but bland. The current need is branded, reusable business PDFs without a large design toolchain.

Decision

Yes

Quality

Higher

Real layout, hierarchy, and print CSS.

Ops burden

Low

Python script, JSON data, source-controlled templates.

Risk

Medium

CSS support and native dependencies must be verified.

What matters

  • Readable extracted text
  • A4 page discipline
  • Long values wrap cleanly
  • No JavaScript dependency

Risks

  • Unsupported CSS surprises
  • Font differences across machines
  • Pretty sample data hides overflow bugs

Recommended next action

Use WeasyPrint for owned designed PDFs; keep Playwright for JS-heavy pages.

It keeps the authoring model simple while producing substantially better PDFs than generic exports.
